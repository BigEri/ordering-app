# Ordering app

Vytvořená struktura:

- `app/menu/page.tsx`
- `app/cart/page.tsx`
- `lib/supabase/client.ts`
- `components/MenuItem.tsx`
- `components/Cart.tsx`

Spuštění (dev):

```bash
npm install
npm run dev
```

Pak otevři:

- `http://localhost:3000/`
- `http://localhost:3000/menu`
- `http://localhost:3000/cart`
